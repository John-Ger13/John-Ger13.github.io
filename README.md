# John Springfield

A standalone, responsive browser-based media guide built with HTML, CSS, and JavaScript.

**Live demo:** https://john-ger13.github.io/

## Features

- Responsive mobile and desktop interface
- Episode/show management
- Season configuration
- Collections
- Website decoration/themes
- Local browser storage (`localStorage`)
- Import/export of local site data
- Random selection
- Subtitle and external-media URL support
- No database or server-side backend required for the standalone edition

## Deployment

This project is a static website.

To deploy with GitHub Pages:

1. Keep `index.html` in the repository root.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Select the `main` branch and `/(root)`.
5. Save.

## Data and privacy

The standalone edition does not require the seller's Supabase project or account. Site configuration is stored locally in the visitor's browser.
